# Менеджер позичених речей

Лабораторна робота №3 з дисципліни «Кросплатформне програмування» (варіант 9).
Облік речей, позичених або переданих іншим людям, із датами повернення.

Flutter-застосунок з орієнтацією на macOS (десктоп). Екрани зроблено за макетами з лабораторної №2
без бізнес-логіки: дані hardcoded (`lib/data/mock_data.dart`), без Firebase і сторонніх пакетів.

## Екрани

- Вхід і відновлення пароля, реєстрація (`lib/features/auth`)
- Головне вікно зі списком речей, пошуком, сортуванням і категоріями (`lib/features/home`)
- Профіль і зміна пароля (`lib/features/profile`)
- Модальні вікна додавання/редагування та видалення запису, екран фотофіксації стану речі (`lib/features/items`)

## Структура

```
lib/
  core/{theme,utils,widgets}   тема, форматування дат, повторно використовувані віджети
  data/                        моделі та тестові дані
  features/{auth,home,items,profile}
```

## Запуск

```
flutter pub get
flutter run -d macos     # або -d chrome
flutter test
```
